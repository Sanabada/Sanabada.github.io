HP Edge AI hackathon, SJSU, 2026

EdgeSupport: on-site IT triage

An IT help-desk assistant that diagnoses laptop problems on a local HP ZGX Nano, so private logs never leave the building.

95% accuracy

on a 20-ticket synthetic test set, against 75% for a rules-only baseline, with zero PII leaked

What I built
I built the original privacy and telemetry pipeline, then led the integration of my teammates' backend and laptop collectors (11 of the team's 16 commits). A local Qwen2.5-7B model answers each ticket three to five times. The ticket stays on site only if the answers agree and cite real evidence. Otherwise it escalates to a person with a reason code.
The hard part
Teaching the system when not to answer. Thresholds are tuned on a calibration set and locked before testing. 107 automated tests pass on the Nano, and short LoRA fine-tuning runs completed on its GPU.

NYC taxi data pipeline in Docker

A batch and real-time data pipeline that runs in Docker, from raw public trip files to a Snowflake warehouse.

What I built
Two Airflow DAGs running in Docker. One finds the latest monthly NYC trip file, cleans it with PySpark, and loads it into Snowflake. The other pulls live New York weather from the OpenWeather API every hour.
The hard part
Safe reruns. Loads go through a staging table and a MERGE so rerunning never duplicates trips, and every Snowflake step runs in a transaction that rolls back on failure.

Speech emotion recognition

Reading emotion from voice, using the surrounding conversation for context.

52.4% Macro-F1

and 55.9% accuracy on IEMOCAP, ahead of MLP and transformer baselines

What I built
A CNN, BiLSTM, and attention model over Log-Mel spectrogram and MFCC features, trained on IEMOCAP and MELD.
The hard part
Emotion classes are badly imbalanced. Focal loss, augmentation, and per-speaker normalization kept the model from just predicting "neutral".
