Asset & Wealth Web App + Data Integrity

Developed a web application supporting asset & wealth workflows. Focus areas: microservices delivery with Spring Boot, strong data integrity/availability using Oracle + MongoDB, and reliability improvements via data replication patterns.

What I shipped

  • Web application delivery: built an application to enhance asset/wealth management by enabling precise, global data dissemination tailored to user needs.
  • Data integrity + availability: used Oracle and MongoDB to keep critical operations robust and highly available.
  • Microservices execution: delivered and supported features using Spring Boot, REST APIs, and microservices in Agile workflows.
  • Replication for reliability: strategically replicated data from Sybase across databases to improve reliability and accessibility of financial records.

Stack snapshot

Spring Boot REST APIs Microservices SQL Oracle MongoDB Sybase replication patterns

Public context (high-level)

In financial systems, correctness and availability are core requirements: design choices often trade off latency, consistency guarantees, and operational simplicity.

Engineering decisions I’m proud of

  • Integrity-first thinking: prioritized correctness and predictable behavior for critical workflows.
  • Supportable services: designed APIs that were easier to test, operate, and evolve under real delivery pressure.
  • Replication used deliberately: improved availability and access patterns while keeping a strong handle on consistency expectations.
